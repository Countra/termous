Termous 把 SSH 连接、主机与凭据、远程文件、服务器运维、网络转发和常用命令整合到一个桌面工作台中。它面向经常在多台服务器之间切换的开发者、运维人员和技术团队，目标是减少窗口切换、降低误操作，并让终端、文件与主机状态始终保持清晰的上下文。

## 为什么选择 Termous

| 痛点 | Termous 的解决方式 |
| --- | --- |
| 主机、凭据、终端和文件工具分散 | 用一个工作站统一管理连接、文件与远程运维操作 |
| 复杂网络环境需要多套连接工具 | 为主机配置跳板机或 HTTP / SOCKS5 代理，并让 SSH、SFTP 和转发共享连接链路 |
| 多个 SSH 会话容易混乱 | 通过会话标签、颜色、固定、复制和分屏保持清晰上下文 |
| 终端与远程文件来回切换 | 通过 SFTP、目录跟随、书签和工作站文件区在同一会话内协同操作 |
| 常用命令和服务器操作重复 | 使用代码片段、Shell 别名，以及进程、服务和 Docker 管理集中处理 |

## 快速开始

1. 从 [Releases](https://github.com/Countra/termous/releases) 下载适合当前系统的安装包。
2. 打开 Termous，新增凭据与主机；需要时可配置跳板机或连接代理。
3. 点击顶部的“连接”，选择目标主机后进入 SSH 工作站。
4. 在右侧功能区使用文件、系统信息、监控、进程、服务、Docker、防火墙、端口转发、命令别名和代码片段。
5. 需要更大操作空间时，可进入独立“文件”页面管理远程目录、书签、本地下载位置和传输任务。

## 功能亮点

### SSH 工作站

- 多 SSH 会话标签，支持复制、重命名、固定和颜色标记。
- 支持终端分屏，适合并行查看日志、执行命令和对比环境。
- 支持上下文感知的智能补全，聚合已启用的命令别名、安全单行代码片段、远端已落盘历史，以及 `cd` / `pushd` 的目录候选。
- 智能补全只插入候选，不自动执行命令；Tab 始终保留给远端 Shell 的原生补全。
- 支持终端搜索和上下文感知右键菜单，可复制、查找、粘贴、打开受支持的 HTTP/HTTPS 链接或在工作站文件区定位远程路径。
- 工作站文件区可与终端双向跟随目录，并提供紧凑的远程目录书签入口。
- Windows 支持本地 PowerShell / CMD 会话。
- 支持终端字体、字号、行高、字符间距、光标和主题设置。

### 主机、凭据与连接代理

- 主机分组、标签、收藏、最近使用和在线延迟检测。
- 支持密码和私钥认证，可导入加密私钥并关联口令凭据。
- 支持自定义主机图标、备注、跳板机和平台信息。
- 支持为主机配置无认证的 HTTP 或 SOCKS5 代理；连接失败不会自动回退直连。
- SSH、跳板机、SFTP 和端口转发使用统一的主机指纹信任流程。
- 凭据与主机分离管理，避免在多个主机配置中重复维护敏感信息。

### 远程文件与目录跟随

- SFTP 多会话文件管理。
- 支持上传、下载、移动、删除、重命名和权限设置。
- 支持拖拽上传到当前目录或指定文件夹。
- 支持远程目录书签、本地下载位置和带实时进度的传输列表。
- 支持文本文件在线编辑和图片文件在线预览。
- 终端与工作站文件区可双向同步当前目录；断线后保留最后成功目录并提供手动恢复。

### 服务器运维

- Linux 系统信息展示。
- CPU、内存、网络和磁盘监控。
- Linux 进程查看、搜索与终止。
- systemd 服务状态、控制和日志查看。
- Docker 容器状态、控制、详情和日志查看。
- iptables / nftables 防火墙规则管理与持久化辅助。

### 命令与网络工具

- 常用代码片段支持分组、变量和发送到当前会话。
- 支持管理 Bash、Zsh 和 Fish 的 Termous 受管命令别名。
- 智能补全索引在 SSH 连接就绪后异步建立，不扫描远端 `$PATH`，索引失败不会影响终端、SFTP 或目录跟随。
- 支持本地端口转发、远程端口转发和动态代理。
- 运行中的转发可查看连接数、累计流量和实时发送/接收速率，并支持重启和停止。

### 数据、安全与桌面体验

- 自定义窗口、托盘菜单和最小化到托盘。
- 暗色 / 亮色主题。
- 支持应用内检查、下载和安装更新。
- 支持加密 `.tobp` 备份，以及完整、合并和选择性恢复。
- 关闭前提供连接清理提醒。
- 简体中文和英文界面。

## 适合场景

- 日常登录多台 Linux 服务器处理问题。
- 在 SSH 会话和远程文件之间频繁切换。
- 同时观察系统资源、管理进程与服务、查看配置文件和执行诊断命令。
- 临时配置端口转发或代理通道。
- 希望把常用服务器命令沉淀为代码片段或远程 Shell 别名。

## 安全与隐私

Termous 的定位是本地桌面工作站。凭据由本地 Vault 管理，SSH 主机身份通过统一的指纹信任流程确认；加密备份不会导出当前设备的 Vault 主密钥，应用更新在安装前会校验下载产物。当前连接代理仅支持不含认证信息的 HTTP 与 SOCKS5 地址，避免代理凭据进入主机配置、日志或备份。智能补全只在当前 SSH 会话内存中保存有界的远端历史和目录索引，不写入本地数据库、备份、LocalStorage 或日志；关闭会话后索引随即释放。
