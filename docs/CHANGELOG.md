# Changelog

本文件记录 Termous 的核心版本变更，格式遵循 Keep a Changelog，并使用语义化版本号。

## [0.3.0] - 2026-07-26

### Added

- 新增应用内更新能力，可从版本入口打开“关于 Termous”，完成更新检查、下载、进度查看、失败重试和安装确认；设置页支持配置自动检查频率与自动下载。
- 新增加密的数据备份与恢复，支持 Termous `.tobp` 备份文件导入导出、完整恢复、合并恢复、选择性恢复、冲突预览与逐项处理，并通过原子交换降低恢复中断造成的数据损坏风险。
- 新增 SSH 密钥生成、解析、预览和保存流程，支持导入加密私钥，并可关联已有或新建的口令凭据。
- 新增统一的主机指纹信任中心，使终端、跳板机、SFTP 和端口转发共享一致的指纹确认与信任状态。
- 工作站新增会话级文件区，支持在 SSH 会话中浏览和操作远程文件，并提供终端与文件目录的双向跟随、文件传输和进度反馈。
- 代码片段新增分组、搜索、收藏、标签筛选与排序，并完善变量校验、变量复用和光标位置插入。

### Changed

- 全面重构独立文件工作区，统一文件会话标签、路径导航、列表选择、书签快捷导航、本地下载控制台和传输抽屉；远程文件可拖放到明确的本地下载目标。
- 重构主机、凭据和代码片段管理体验，统一搜索筛选、分组排序、主从编辑、未保存变更保护和响应式布局。
- 重构端口转发配置与运行视图，优化转发模式选择、端点关系、运行状态、指标展示和窄窗口布局。
- 目录跟随改为按需建立管理连接并复用通道与组件校验结果，提升首次和后续跟随速度，同时支持低会话限制与嵌套 Shell 恢复。
- SSH 连接统一使用内置的受管实现，不再提供系统 SSH 模式；原生 PTY、Shell 启动、MOTD、Profile 和提示符行为保持不变。
- Core HTTP 服务全面迁移至 Gin，并改用 Handler 注释自动生成 Swagger 文档，在保持现有 `/api/v1`、认证、WebSocket 和响应契约的同时完善服务生命周期管理。
- 统一工作站与文件管理的会话标签、连接入口及加载反馈，改善会话切换、关闭和连接失效时的状态辨识。

### Fixed

- 修复 SFTP 连接断开后重试失败、状态文案缺失和旧会话事件覆盖新连接的问题；断线时会保留最后成功目录并支持可靠的手动恢复。
- 修复目录跟随首次准备过慢、状态回退、目录切换无响应、迟到结果覆盖和 Bash 提示符刷新异常，并完善远端运行目录在正常关闭与异常退出后的清理。
- 修复文件会话创建与关闭竞态、关闭过程缺少反馈、重复关闭及关闭期间仍可操作的问题。
- 修复上传与传输状态乱序、连接进度回退、目录刷新滚动抖动、长路径导航和传输列表处理非法路径时崩溃的问题。
- 修复已终止端口转发的运行实例残留，以及书签跨组移动后的排序异常。
- 修复启动进度停止动画、窄栏服务状态溢出、Docker 检测加载反馈和后端连接异常提示布局。

### Security

- 加密备份会校验密码、归档完整性、路径边界、条目类型和资源限额，跨设备恢复不会导出本机 Vault 主密钥。
- SSH 私钥导入与保存通过受限的桌面 IPC 和文件边界执行，并对来源、文件大小、目标冲突和失败回滚进行校验。
- 主机指纹确认使用有界、可过期的信任请求，避免终端、SFTP 或端口转发绕过统一的主机身份校验。
- 更新安装使用可信 IPC 和单一状态事务，并在启动安装程序前协调 Core 安全退出、校验更新产物与安装权限。

## [0.2.0] - 2026-07-11

### Added

- 工作站新增 Linux 进程管理，支持按名称、命令行、PID 和监听端口搜索，按 CPU 或内存占用排序，并可查看详情和终止进程。
- 新增 Docker 管理，支持浏览容器状态、执行常用控制操作、查看容器详情，以及搜索和跟随容器日志。
- 新增 Linux systemd 服务管理，支持服务搜索、状态与详情查看、启动、停止、重启、开机启动设置和日志查看。
- 系统信息新增网卡与多 IP 地址展示，系统监控新增磁盘 I/O 实时数据和更清晰的磁盘分区视图。
- 新增独立的应用启动加载窗口，并提供 Windows x64、Linux x64、macOS x64 与 macOS arm64 安装包。

### Changed

- 应用主题切换迁移至设置页并持久化，启动窗口会同步使用当前的亮色或暗色主题。
- 优化进程、Docker、系统服务和磁盘监控在窄侧栏中的信息层级、筛选交互、刷新反馈与详情布局。

### Fixed

- 修复 Vim 等全屏终端程序中的 Escape、命令模式和组合按键无法可靠传输的问题。
- 修复部分旧版 systemd 环境的服务列表兼容性问题，以及 Docker 容器日志顺序不稳定的问题。

## [0.1.0] - 2026-07-08

### Added

- 首个可用的 SSH 工作站体验，支持主机管理、凭据管理、SSH 会话连接、本地终端和终端分屏。
- 完整的远程文件管理能力，支持 SFTP 浏览、上传、下载、书签、本地目录映射、在线文本编辑和图片预览。
- 服务器运维辅助能力，包含代码片段发送、端口转发、系统信息、系统监控和 Linux 防火墙管理。
- 桌面端基础能力，包含托盘菜单、关闭到托盘、应用图标、版本展示、终端样式设置和多语言资源管理。
