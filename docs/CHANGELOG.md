# Changelog

本文件记录 Termous 的核心版本变更，格式遵循 Keep a Changelog，并使用语义化版本号。

## [0.5.0] - 2026-08-13

### Added

- 新增会话命令台，支持向当前、指定或全部已连接 SSH 会话并行发送完整单行 Shell 命令，集中查看执行结果与退出码，并提供任务恢复、输入锁、单目标或整批中断，以及可折叠、可调高度的底部抽屉。
- 新增当前用户的远程定时任务管理，支持任务筛选、结构化计划编辑、Cron 原文高级编辑、只读降级、并发冲突恢复和不确定写入保护。
- 新增可复用的主机图标库，支持批量导入、预览、搜索选择、改名、拖拽排序和引用保护，并统一主机目录、工作台、文件区与别名同步中的图标展示。
- 新增命令别名多主机串行同步，支持按 Shell 类型匹配目标、原子合并缺失别名、逐主机进度与结果、活动任务恢复及取消，并兼容代理、跳板机和 Host Key 确认。
- 新增上下文感知的智能命令补全，聚合 Termous Alias、代码片段、远端历史、目录和 Bash 原生命令候选；各来源可独立启停，候选支持键盘浏览和安全插入。
- 新增快捷键管理页面，支持动作搜索、按键录制、冲突校验和恢复默认值，并覆盖终端、文件列表、远程编辑器及工作站常用操作。
- 系统监控新增 CPU 总体趋势与逐核心实时使用率视图。
- 终端设置新增 SSH 平滑滚动开关，可动态应用于已有 SSH 会话且不影响本地终端。

### Changed

- 命令台回显区现在仅展示命令产生的结果内容，不再重复显示输入命令和收尾提示符，同时继续保留每个会话的可信退出码。
- 完成前后端模块化架构重组，收敛领域、运行时、API、样式和跨进程边界；既有 HTTP/WebSocket 接口、SQLite 数据、备份格式及核心运行行为保持兼容。
- 统一主机图标的资源生命周期、排序和缓存刷新规则；主机更新或删除不再隐式回收仍可复用的图标。
- 优化工作台右侧功能导航、终端分屏尺寸交互，以及新增/编辑模式、筛选浮层、表单和弹层的视觉一致性。

### Fixed

- 修复终端分屏首次按住分隔线拖动会因布局状态回写而失效的问题，并修正面板默认尺寸和最小尺寸的百分比约束。
- 修复命令派发在快速输出、断线、中断、取消和 WebSocket 重连时可能出现结果缺口、状态不确定、重复命令回显或提示符泄漏的问题。
- 修复命令别名同步在请求结果不明确、跨会话恢复、目标连接超时、取消和迟到事件场景中的状态、错误分类与资源释放问题。
- 修复智能补全在提示符观察、SSH 重连、会话切换、候选截断和迟到响应场景中的状态恢复与边界处理问题。
- 修复重复启动可能创建多个应用实例、关闭窗口未正确遵循“最小化到托盘”设置，以及启动动画过早消失的问题。
- 修复主机图标迁移、删除回滚和并发文件操作可能导致数据库记录与图标文件不一致的问题。
- 修复每周定时计划中的星期顺序不符合常用阅读习惯，以及部分连接、筛选和弹层界面的空间与层级问题。

### Security

- Core 现在要求显式配置 API Token，并限制 HTTP 服务只监听本机回环地址；配置不安全时会拒绝启动。
- 会话命令台仅在 SSH 会话处于可信空闲提示符时写入原 PTY，执行期间锁定输入；命令正文和输出仅用于内存任务与实时展示，不写入数据库、备份或日志。
- 定时任务写入通过独立 SSH 执行通道、变更 Token 前置校验和提交后复读确认，避免并发修改被静默覆盖。
- 别名同步复用现有凭据、代理、跳板机与 Host Key 信任机制，并在独立短生命周期连接中执行语法校验和原子提交。

## [0.4.0] - 2026-07-30

### Added

- 新增主机连接代理管理，支持配置 HTTP 与 SOCKS5 代理、按主机选择连接代理，并将代理链路统一应用于 SSH、SFTP、目录跟随和端口转发。
- 工作站新增远程命令别名管理，支持 Bash、Zsh 和 Fish 别名的搜索、新建、编辑、启停与删除，并提供启动桥接修复和旧版配置更新。
- 工作站文件区新增紧凑书签面板，支持分组浏览、搜索、快速跳转，以及收藏或编辑当前远程目录。
- 端口转发新增实时发送与接收速率、累计流量详情，以及运行实例的重启和停止操作。
- 终端新增上下文感知右键菜单，可根据选区、链接、远程路径和连接状态提供复制、查找、粘贴、打开链接、在工作站文件区定位路径和重新连接等操作。

### Changed

- 终端目录跟随协议与可见输出、终端回放解耦，减少普通命令和高延迟连接中的提示符重复刷新，同时保留目录变化的即时同步。
- 工作站空会话新增直接连接入口，最近主机改为全局排序列表，并统一主机连接窗口的固定高度和会话状态反馈。
- 优化工作站文件区的书签、单击进入目录、文件会话恢复和本地下载目录交互。
- 将语言选项归入“通用”设置，简化设置页的信息层级。
- 统一书签与书签分组的删除确认交互，完善删除入口和防重复提交状态。

### Fixed

- 修复目录跟随发生超时、快速切换、SFTP 断线或迟到响应后可能持续加载、状态回退或无法继续同步的问题。
- 修复 SSH 会话重启后遗留失效文件会话，以及断开的 SFTP 仍响应终端目录变化的问题。
- 修复代理连接场景下目录跟随准备状态无法结束、失败状态不准确和重新连接后状态未正确恢复的问题。
- 修复端口转发在高延迟、WebSocket 重连与状态轮询竞态下可能出现的状态回退、重复操作和运行实例残留。
- 修复终端搜索上下切换会隔项跳转的问题，并完善跨会话高亮清理、输入法确认和焦点恢复。
- 修复 Bash、Zsh 和 Fish 别名桥接的兼容性问题，并支持将同路径的旧版受管配置安全更新为当前模板。

### Security

- 连接代理配置仅接受受支持的协议、主机和显式端口，拒绝凭据信息、路径、查询参数和片段，代理失败时不会自动回退直连。
- 终端外部链接仅允许通过受限桌面桥接打开合法的 HTTP 或 HTTPS 地址，并拒绝用户信息、控制字符和畸形 URL。
- 远程路径识别不会执行环境变量、通配符或命令替换；命令别名配置通过可信路径校验、语法检查和原子替换后写入。

## [0.3.0] - 2026-07-26

### Added

- 新增应用内更新能力，可从版本入口打开“关于 Termous”，完成更新检查、下载、进度查看、失败重试和安装确认；设置页支持配置自动检查频率与自动下载。
- 新增加密的数据备份与恢复，支持 Termous `.tobp` 备份文件导入导出、完整恢复、合并恢复、选择性恢复、冲突预览与逐项处理，并通过原子交换降低恢复中断造成的数据损坏风险。
- 新增 SSH 密钥生成、解析、预览和保存流程，支持导入加密私钥，并可关联已有或新建的口令凭据。
- 新增统一的主机指纹信任中心，使终端、跳板机、SFTP 和端口转发共享一致的指纹确认与信任状态。
- 工作站新增会话级文件区，支持在 SSH 会话中浏览和操作远程文件，并提供终端与文件目录的双向跟随、文件传输和进度反馈。
- 代码片段新增分组、搜索、收藏、标签筛选与排序，并完善变量校验、变量复用和光标位置插入。

### Changed

- 全面重构独立文件工作区，统一文件会话标签、路径导航、列表选择、书签快捷导航、本地下载控制台和传输抽屉；远程文件可拖放到明确的本地下载目标。
- 重构主机、凭据和代码片段管理体验，统一搜索筛选、分组排序、主从编辑、未保存变更保护和响应式布局。
- 重构端口转发配置与运行视图，优化转发模式选择、端点关系、运行状态、指标展示和窄窗口布局。
- 目录跟随改为按需建立管理连接并复用通道与组件校验结果，提升首次和后续跟随速度，同时支持低会话限制与嵌套 Shell 恢复。
- SSH 连接统一使用内置的受管实现，不再提供系统 SSH 模式；原生 PTY、Shell 启动、MOTD、Profile 和提示符行为保持不变。
- Core HTTP 服务全面迁移至 Gin，并改用 Handler 注释自动生成 Swagger 文档，在保持现有 `/api/v1`、认证、WebSocket 和响应契约的同时完善服务生命周期管理。
- 统一工作站与文件管理的会话标签、连接入口及加载反馈，改善会话切换、关闭和连接失效时的状态辨识。

### Fixed

- 修复 SFTP 连接断开后重试失败、状态文案缺失和旧会话事件覆盖新连接的问题；断线时会保留最后成功目录并支持可靠的手动恢复。
- 修复目录跟随首次准备过慢、状态回退、目录切换无响应、迟到结果覆盖和 Bash 提示符刷新异常，并完善远端运行目录在正常关闭与异常退出后的清理。
- 修复文件会话创建与关闭竞态、关闭过程缺少反馈、重复关闭及关闭期间仍可操作的问题。
- 修复上传与传输状态乱序、连接进度回退、目录刷新滚动抖动、长路径导航和传输列表处理非法路径时崩溃的问题。
- 修复已终止端口转发的运行实例残留，以及书签跨组移动后的排序异常。
- 修复启动进度停止动画、窄栏服务状态溢出、Docker 检测加载反馈和后端连接异常提示布局。

### Security

- 加密备份会校验密码、归档完整性、路径边界、条目类型和资源限额，跨设备恢复不会导出本机 Vault 主密钥。
- SSH 私钥导入与保存通过受限的桌面 IPC 和文件边界执行，并对来源、文件大小、目标冲突和失败回滚进行校验。
- 主机指纹确认使用有界、可过期的信任请求，避免终端、SFTP 或端口转发绕过统一的主机身份校验。
- 更新安装使用可信 IPC 和单一状态事务，并在启动安装程序前协调 Core 安全退出、校验更新产物与安装权限。

## [0.2.0] - 2026-07-11

### Added

- 工作站新增 Linux 进程管理，支持按名称、命令行、PID 和监听端口搜索，按 CPU 或内存占用排序，并可查看详情和终止进程。
- 新增 Docker 管理，支持浏览容器状态、执行常用控制操作、查看容器详情，以及搜索和跟随容器日志。
- 新增 Linux systemd 服务管理，支持服务搜索、状态与详情查看、启动、停止、重启、开机启动设置和日志查看。
- 系统信息新增网卡与多 IP 地址展示，系统监控新增磁盘 I/O 实时数据和更清晰的磁盘分区视图。
- 新增独立的应用启动加载窗口，并提供 Windows x64、Linux x64、macOS x64 与 macOS arm64 安装包。

### Changed

- 应用主题切换迁移至设置页并持久化，启动窗口会同步使用当前的亮色或暗色主题。
- 优化进程、Docker、系统服务和磁盘监控在窄侧栏中的信息层级、筛选交互、刷新反馈与详情布局。

### Fixed

- 修复 Vim 等全屏终端程序中的 Escape、命令模式和组合按键无法可靠传输的问题。
- 修复部分旧版 systemd 环境的服务列表兼容性问题，以及 Docker 容器日志顺序不稳定的问题。

## [0.1.0] - 2026-07-08

### Added

- 首个可用的 SSH 工作站体验，支持主机管理、凭据管理、SSH 会话连接、本地终端和终端分屏。
- 完整的远程文件管理能力，支持 SFTP 浏览、上传、下载、书签、本地目录映射、在线文本编辑和图片预览。
- 服务器运维辅助能力，包含代码片段发送、端口转发、系统信息、系统监控和 Linux 防火墙管理。
- 桌面端基础能力，包含托盘菜单、关闭到托盘、应用图标、版本展示、终端样式设置和多语言资源管理。
