# Changelog

本文件记录 Termous 的核心版本变更，格式遵循 Keep a Changelog，并使用语义化版本号。

## [0.1.0] - 2026-07-08

### Added

- 首个可用的 SSH 工作站体验，支持主机管理、凭据管理、SSH 会话连接、本地终端和终端分屏。
- 完整的远程文件管理能力，支持 SFTP 浏览、上传、下载、书签、本地目录映射、在线文本编辑和图片预览。
- 服务器运维辅助能力，包含代码片段发送、端口转发、系统信息、系统监控和 Linux 防火墙管理。
- 桌面端基础能力，包含托盘菜单、关闭到托盘、应用图标、版本展示、终端样式设置和多语言资源管理。
