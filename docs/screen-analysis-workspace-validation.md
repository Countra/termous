## 实现边界

- 主页面保留工作台和执行记录，画面分析迁入独立 Ant Design Modal；当前分析和历史共用画布、筛选、详情及导出面板。

- 几何接口兼容无参调用，增加元素／OCR 图层及领域筛选。OCR 几何使用自己的中心点和所属元素编号；列表、几何和渲染共用筛选实现。
- 应用前后校验固定编辑上下文及 Core `action-context`；模板裁剪、上传和草稿确认完成后才交接原图并关闭。窗口间同步轻量状态，关闭释放结果正文、图片 URL 和界面读取。
- 不修改 Python 推理、原始结果编码、数据库迁移、MCP 工具及桌面输入授权。
