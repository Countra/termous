# 工作台分栏验收

日期：2026-10-25。

## 实现边界

- 执行链和步骤属性支持拖动、键盘调整、双击重置和独立收起；收起后宽度归零，顶部文字按钮保留入口，展开恢复最近宽度。
- 编辑区不足 860px 时通过“执行链／画面／步骤属性”在工作台内切换，不使用属性抽屉或竖向展开栏；中央截图保持挂载，隐藏内容不可交互。
- 窗口适配不覆盖展开宽度，用户调整结束才同步轻量展示状态，不修改流程定义和执行协议。
- 复用项目已有分栏库、Ant Design 分段控件及主题变量，没有增加依赖；按钮选中态和面板入场使用轻量动画，支持减少动态效果。

## 实际通过

- Web 类型检查；代码 lint、样式 lint 和架构边界检查。
- 工作流 UI：23 个文件、142 项测试，包括折叠、原位切换、画布挂载保持及宽度适配。
- 独立窗口命令合同：6 项测试，覆盖有界尺寸、非法参数和旧展示状态兼容。
- In-app Browser：深浅主题、中英文、宽窄窗口、真实鼠标拖动、方向键调整、双击重置和折叠恢复。
- Electron：真实指针拖动两侧、折叠恢复、主窗口与独立窗口往返后的宽度恢复；原有 OCR 范围、草稿、运行配置、执行控制、窗口关闭与崩溃恢复回归通过。
- 分析弹层连续开关 50 次的既有回归通过，最终 DOM 数量未累积。

## OCR 测试结果交互补充验收（2026-10-25）

- 结果整行可选，显示原始编号、文字、像素边界和百分比置信度；截图文字框可点击，列表和画面共用选中状态。点击其他页的文字框会定位到对应结果页，只滚动列表容器。
- 选择只填入正文，保留匹配方式、识别范围、推理参数及拖动目标的锚点、偏移、序号。参数绑定时只高亮，不覆盖正文。
- 填入文字后保留同一次测试供重复选择，重新测试才更新匹配结果。手动改条件、切换步骤或范围仍清除旧观察；不额外截图或重新推理。按后续交互调整移除 OCR 列表解释行和底部只读说明栏，释放结果与画面空间。
- 浏览器验收发现窄窗口分栏重新注册会改变内部顺序，固定键顺序恢复尺寸可能将空间分配给隐藏栏。改为按当前布局顺序恢复，并约束当前画面占满窄窗。
- 实际通过：4 个 UI 测试文件、29 项测试；Web 类型检查、相关代码与样式 lint、样式债务及架构检查。
- In-app Browser 实际验证深色中文、浅色英文、重复选择、列表与画面联动；使用本地合成 OCR 数据，不连接远端。
- Electron 独立窗口回归通过：新增双向选择、窄窗口四次标签切换及选中状态保留检查；原有范围绘制、媒体转发、草稿交接、运行控制和崩溃恢复同时通过。
