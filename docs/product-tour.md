# 用户向导

使用向导从帮助菜单进入，先选择基础导览或专题。首次使用且没有连接配置时，只自动展示基础导览。已有旧版向导记录的用户不会因内容升级被强制重新引导。

选择页将基础导览与功能专题分区，宽窗口左右排列，专题采用等宽三列入口，窄窗口逐级调整为两列或单列。基础导览先介绍凭据，再介绍主机；连接专题进一步说明凭据创建与连接配置。每个专题完成后返回选择页，显示刚看完的专题及已完成标记，可继续选择其他功能。讲解中的“专题列表”随时返回选择页，不计为完成；关闭按钮、Esc 或点击遮罩退出整轮向导。启动失败或业务阻塞时不自动弹回选择页。

## 模块职责

- `features/product-tour/model/productTourTypes.ts`：步骤、定位、路由和页面准备契约。
- `productTourSteps.ts`、`productTourFeatureSteps.ts`、`productTourAssistantSteps.ts`：通用、桌面与助手领域步骤；双语文案由语言资源提供。
- `productTourTopics.ts`：专题、内容版本及步骤顺序，同一步骤可被多个专题复用。
- `productTourTargets.ts`：一次解析可见目标与对应文案，排除隐藏、缓存、禁用和不可交互区域。
- `productTourProgress.ts`：浏览器本地的专题完成记录和基础导览展示记录，不参与业务同步。
- `ProductTourGuide`：自动展示策略、专题选择和一次引导的生命周期。
- `ProductTourController`、`ProductTourEngine`：页面准备、Driver.js 展示、键盘控制、取消与资源清理。
- `app/main/App.tsx`：业务导航与草稿保护；功能模块只暴露稳定的 `data-tour` 锚点和必要的视图切换意图。

## 引导边界

专题步骤仅作讲解，禁止操作高亮区域。页面准备只允许导航、切换设置的外层与外部扩展子页签，以及切换自动化的工作台／执行记录；不打开导出窗、文件选择器或其他业务操作。

导航必须等待应用返回结果，并在取消、应用未就绪、忙碌或有冲突草稿时停止。准备等待有界，不等待联网、安装或认证。桌面自动化只切换展示视图，保留草稿、选中流程、筛选、执行目标和已有任务；独立窗口中的工作区不接收向导视图切换。视图指令只消费一次，整轮退出时清除，重新进入专题列表不会重放旧指令。

`onSessionChange` 覆盖专题选择、首步准备、讲解及返回列表；`onActiveChange` 仅表示讲解已展示。默认关闭的 `guided` 上下文暂缓新 MCP 准备、待处理资源导入、新截图观察及文件自动远程请求。已有请求和 Run 继续运行，助手控制器与订阅保持工作。向导导航离开助手时保留已有准备所有权，退出整轮向导后按当前页面恢复调度或释放；Core 未就绪和宿主卸载仍执行清理。

有条件的区域使用 `element` 指向详细控件，`fallbackElement` 指向父级工作区或真实入口，`fallbackDescription` 说明条件及入口。目标和文案来自同一次解析；父级也不可见时居中说明。不为引导创建示例流程、切换执行目标或自动登录。流程导入导出优先定位“功能”，未打开流程时定位总览的导入入口。

## 弹层与焦点

普通弹层保持公共层级并优先处理键盘，审批弹层不能被向导覆盖。正在被讲解的设置或账号认证弹层使用 `termous-product-tour-surface` 标记并降至向导下方；退出引导后恢复默认层级。未登录时，账号专题复用弹层内容作为降级锚点，不发起登录或扫码。专题选择层完全关闭后再启动 Driver，关闭后销毁内容，避免遮挡或争抢焦点。

高亮前保存目标原有的 ARIA 弹层属性，切换步骤、关闭或卸载后恢复，避免 Driver 清理时破坏业务控件的状态声明。

应用失去就绪状态时，关闭专题选择并释放引导会话、未启动的选择和临时完成提示。恢复后不自动续跑，用户可重新从帮助菜单进入。

## 进度兼容

- `termous.ui.productTour.completedVersion`：保留旧记录，仅用于识别看过旧向导的用户。
- `termous.ui.productTour.basics.seen`：基础导览实际展示后写入，准备失败不写入。
- `termous.ui.productTour.topic.<id>`：专题完成版本；只有走完专题才写入，关闭和跳过不视为完成。

记录写入保持单调，不能用旧版本覆盖新版本。存储不可用时仍可手动使用，本次应用会话也不会反复自动弹出。无需后端字段或数据库迁移。

当前内容基线为 6。基础导览、主机与连接、远程桌面、自动化、AI 助手、外部扩展与搜索、设备远程控制、工具与集成使用版本 6；文件与挂载、云同步与备份保留版本 5。完成判断和写入均采用专题自身版本。修改共享步骤时，须同步更新所有引用该内容的专题版本。

外部扩展专题介绍将第三方 MCP、Skills 接入内置助手以及联网搜索；工具与集成专题介绍终端工具、端口转发、代码片段，以及外部 AI 客户端通过 Termous MCP 调用工具的配置。

## 扩展与回归

新增专题时，补充步骤契约、专题编排、双语文案与图标。准备动作必须具有明确的取消路径，禁止通过任意 DOM 点击绕过业务导航守卫。

回归重点：新用户与旧记录、跳过与完成、连续重播、深浅主题、设置弹层键盘和审批优先级、未保存草稿、无连接、未登录、AI 未就绪、自动化独立窗口占用，以及结束后的正常操作恢复。

合成界面入口：运行 `node scripts/desktop/workflow-ui-server.mjs`，打开 `http://127.0.0.1:5196/scripts/product-tour/preview.html`。可组合 `?light`、`?en`、`?empty` 和 `?unready` 检查浅色、英文、空扩展及助手未就绪状态；不连接真实 Core、模型或外部服务。入口复用真实设置、助手和流程组件，其余工作区仅提供回退展示。
